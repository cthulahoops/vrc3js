- Dev server: `npm run dev` serves on `APP_ORIGIN` from `.env` (the tailnet address). The OAuth callback pins it to that port, so one runs per machine: stop any other checkout's `scripts/dev.ts` first. Start it detached (`nohup npm run dev > /tmp/vrc3js-dev.log 2>&1 &`) so it outlives background-command time limits. A fresh worktree needs `scripts/setup-worktree.sh` first (T3 Code runs it automatically).
- The RC Together stream is real people's data with no staging copy. Learn its shape only via `npm run dump:entities` (field names, never values); `test/fixtures` is hand-written, so confirm a field there before reading it. Screenshots and browser checks run against fixtures (`npm run verify:screenshot`), never the live dev server.
